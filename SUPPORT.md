# Support

## How to file issues and get help

This project is a **proof of concept / prototype**. It is provided as-is to explore
two brownfield-to-IaC export methods for Azure, and is **not an officially supported
Microsoft product**. There is no SLA, and it may change or be archived without notice.

For bugs, feature ideas, or questions about this repository, please search
[existing issues](../../issues) first, then open a new issue if your topic isn't
already covered. Because this is a best-effort POC, response times will vary.

## Microsoft Support Policy

Support for this project is limited to the resources listed above. For production
Azure infrastructure-as-code support, use the official Azure documentation and support
channels:

- [Azure documentation](https://learn.microsoft.com/azure/)
- [Bicep documentation](https://learn.microsoft.com/azure/azure-resource-manager/bicep/)
- [Azure Verified Modules](https://azure.github.io/Azure-Verified-Modules/)
- [Azure support](https://azure.microsoft.com/support/)
